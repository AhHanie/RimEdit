# RimEdit

A free and open source Windows desktop editor for RimWorld mod XML.
Built to make editing Defs and patches easier.

[Releases](https://github.com/AhHanie/RimEdit/releases) | [Issues](https://github.com/AhHanie/RimEdit/issues) | [Discord](https://discord.gg/FvHTybz3q)

## Installation

To install RimEdit, visit the [Releases page](https://github.com/AhHanie/RimEdit/releases) and download the latest release for your platform:

- **Windows**: download the zipped release, unzip it, and run the RimEdit executable inside the unzipped folder.
- **Linux**: download the AppImage, `.deb`, or `.rpm` package, whichever suits your distribution.

Nightly builds from the latest `development` branch are also published as
[pre-releases](https://github.com/AhHanie/RimEdit/releases) for testing
in-progress work between stable releases. See
[docs/NightlyBuilds.md](docs/NightlyBuilds.md) for details on what they are
and how they're built.
